# Runtime Package Manifest

این archive فقط شامل کد اجرای portal3، assetهای local، migration/schema، installer و مستندات نصب است.

## Included

`admin/`, `customer/`, `includes/`, `assets/`, `bin/`, `storage/.htaccess`, `uploads/.htaccess`, فایل‌های PHP ریشه، Composer metadata، schema و migration، `.env.example`، `README.md`، `INSTALL.md` و `VERSION`.

## Excluded intentionally

`.git/`، `vendor/`، `node_modules/`، `tests/`، `.github/`، ابزارهای PHPStan/PHPUnit، package manager files، فایل‌های گزارش و QA، cache، uploadهای محیط توسعه، `db_config.php`، فایل‌های موقت و build source Tailwind.
