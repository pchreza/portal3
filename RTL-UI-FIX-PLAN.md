# برنامهٔ اصلاح UI/UX و RTL پروژهٔ portal3

این سند baseline ممیزی و معیار پذیرش اصلاحات است. هر مورد پس از تغییر کد باید با lint، آزمون DOM/رفتار و مرور بصری بررسی شود. وضعیت اولیهٔ همهٔ موارد `Open` است.

## معیارهای عمومی پذیرش

هر اصلاح باید بدون شکستن PHP، با `lang="fa" dir="rtl"`، متن فارسی قابل‌خواندن، داده‌های فنی ایزوله، ترتیب منطقی DOM و keyboard، reflow در عرض‌های کوچک، focus قابل مشاهده، و سازگاری light/dark mode عبور کند. برای رفتارهایی که معنای ذاتی LTR دارند، مانند ایمیل، URL، کد، شناسه، تلفن، عدد و مقیاس عددی، جهت باید صریح و مستند باشد؛ RTL بودن shell به‌تنهایی دلیل معکوس‌کردن داده نیست.
